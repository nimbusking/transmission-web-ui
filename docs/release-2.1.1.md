# 2.1.1 登录刷新恢复修复

修复2.1.0登录后刷新返回首页的问题。成功登录后在当前标签页会话中保存认证信息，刷新时重新向同一RPC地址认证并恢复工作台；首次访问仍显示登录页，401/403清除临时记录，错误密码不保存。

记录使用sessionStorage，不写入长期设置或诊断包。同源脚本可读取；浏览器会话恢复行为遵循浏览器设置。存储被禁用时退回手动登录。详见[诊断说明](diagnostics.md#登录刷新恢复211)。

安装交付使用独立2.1.1版本目录，保留2.1.0供安装器恢复。NAS实机升级仍需用户确认结果。

诊断完整回归已完成：三浏览器每场景三次共243项、生产采集与登录15项、四daemon、独立CLI及旧包构建匹配、5000任务性能均通过。见[2.1.1验收证据](validation-evidence/diagnostics-2.1.1/README.md)。首次测试输出目录冲突的失败记录保留。
