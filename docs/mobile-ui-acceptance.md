# 手机端 UI 验收（2026-11-16）

## 范围与方法

本轮覆盖新登录页、手机任务列表，以及配置页的基本设置、网络传输、带宽限制、时段限制、目录字典、额外设置、用户标签、导入预览与服务端变更确认。

浏览器测试使用独立模拟 RPC、独立浏览器存储和触控事件，不修改 19081 的真实下载任务或服务端参数。覆盖 Chromium、Firefox、WebKit，320/360/390/430/600px 窄屏，844×390 横屏，登录页高度缩至380px，以及四套视觉主题的深浅模式。中英文分别检查；英文用于长文案压力，中文用于实际使用界面。

## 发现与修复

| 问题 | 修复与验收依据 |
| --- | --- |
| 手机任务左侧可见勾选框没有垂直居中，通用 `> div` 选择器还会把复选框当成可伸缩内容 | 使用独立内容类与复选框类；可见方框中心与任务卡片中心误差不超过1px，点击区域至少44×44px；触控勾选不打开详情，点击任务标题正常打开并可关闭详情 |
| 320px配置表单的两列布局挤压长文案、数字和单位 | 600px以下改为上下排列，数字和时间输入完整占用可用宽度，桌面继续保留紧凑布局 |
| 标签导入的原生文件输入把标题挤成竖排 | 手机端文件选择区改为上下排列，限制输入宽度；标签名称和描述独立占满一行 |
| 配置输入默认14px，触控按钮/开关部分过小 | 手机/触控设备输入字号16px，主要表单、按钮、复选框、关闭按钮等触控高度44px；登录密码显示和明暗按钮扩大触控区域 |
| 时段选择器的 `input-props` 不被组件支持，开始/结束时间标签未关联输入 | 使用包含时间控件的原生label；按可访问名称查找、触控打开弹层并检查边界 |
| 导入确认的三列表格在320px长路径下过度断字 | 手机端每项按名称、当前值、导入值上下展示；桌面仍为表格，保持确认后才修改服务端 |

## 行为验收

- 默认打开登录页后不会自动进入工作台；登录失败可重试，提交后清空密码。
- 登录语言切换、密码显示/隐藏、深浅模式切换可操作；高度缩短时提交按钮可滚动到达。
- 配置七个分类可切换；对话框、内容区和当前分类没有非预期横向溢出。
- 目录建议、时间选择、颜色选择弹层位于可视宽度内。
- 模拟服务端保存完成后保存按钮恢复禁用；重新打开能读回新目录。
- 本地标签、目录保存后重新打开能读回，导入预览不会提前写入服务端。
- 横屏时底部操作和关闭入口可达；桌面四主题深浅对比度/几何回归独立执行。

## 最终结果与部署

- 最终生产构建：63项三浏览器测试全部通过（手机专项48项、登录6项、桌面配置外观回归9项）。
- `npm run check`通过：124项单元测试、lint、类型检查、构建、资源预算及816个旧版文件完整性；最终导入确认样式调整后再次通过生产构建、相关lint及格式检查。
- 已部署到19081。77个HTTP静态资源摘要与验收构建一致；保留原运行配置、旧hash资源，不重启对照容器。
- 19081实际页面只读复核：390px视口中，7条真实任务的勾选框中心偏差约0.4px；配置弹窗宽370px，横向溢出0px。未保存真实服务端参数或操作下载任务。
- 证据：`artifacts/mobile-ui-audit/results.json`、`browsers.log`、`checks.log`、`final-build.log`、`build-manifest.json`及该目录下手机截图。截图使用模拟数据，实页观察单独记入results.json。

## 验证边界

这是浏览器响应式与触控模拟验收，不是实体 iPhone/Android 全机型认证。380px高度用于验证窗口缩小时的滚动可达性，不能代替真机软键盘、地址栏收放、系统文件选择器、自动填充和刘海安全区检查。16px字号是降低iOS聚焦缩放风险的措施，未声称实际测过所有iOS版本。服务端修改在模拟RPC中验证，本轮不以此证明真实daemon设置的执行效果。未调用外部Tracker服务。

测试入口：`tests/e2e/mobile-audit.spec.ts`、`tests/e2e/login.spec.ts`、`tests/e2e/settings-appearance.spec.ts`。最终运行结果与截图见 `artifacts/mobile-ui-audit/`。
