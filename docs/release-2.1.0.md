# 2.1.0 发行说明

新增浏览器本地诊断和人工导出，无需日志接收服务。登录页与关于页提供同一入口，可关闭采集、清除当前实例日志、导出当前/历史记录及故障片段。

增强录制支持全量/增量刷新、任务概览选择/读取、批量启停、重连和状态协调；记录经过脱敏的检查点、业务动作及RPC过程。只在记录完整且满足协议约束时标记replayable。超限、仍有操作执行、跨标签设置变更及范围外操作会明确标记不可重放。

提供独立开发重放入口和命令行，使用真实store及RpcClient执行录制输入，阻断真实RPC，输出状态差异、事件消费和源/目标构建标识。candidate模式要求显式正确性断言，用于验证修复。

默认日志保留1000条/2MiB、30分钟窗口；持久摘要24小时过期，故障片段/增强包7天过期，实例20MiB、站点40MiB。IndexedDB不可用时退回内存；增强录制要求HTTPS或localhost。数据由用户手动下载和提交，不自动上传。

增强录制最多5分钟、10000事件、10MiB，单事件512KiB；大响应、缺失数据、敏感文本替换导致的差异可能使故障无法重放。它不能还原浏览器进程崩溃、原始文件名相关缺陷或服务端真实执行过程。

操作和本地路径见[诊断与重放说明](diagnostics.md)。实际验收与限制见[实施记录](../openspec/changes/add-local-diagnostics-replay/implementation.md)。本文件说明代码交付范围，不表示已发布GitHub Release或部署到运行实例。
