# 2.1.3 工作台直接恢复

已有登录会话时，刷新直接呈现工作台结构，后台重新认证并读取任务数据；不显示登录页或整页加载中。认证和初始化完成前工作台不可操作，不使用旧任务数据冒充当前服务端状态。认证明确失效才返回登录页。首次访问仍显示登录表单。

当前标签页按页面路径保存RPC地址关联，认证信息仍按完整RPC地址隔离；运行配置加载后重新核对地址，不会把其他实例的会话作为当前实例认证。诊断IndexedDB初始化不再位于登录恢复的串行等待路径。

会话存储不可用时仍可手动登录。浏览器标签页会话的生命周期与2.1.1相同。安装版本独立保留以支持恢复。

本机验收与19081更新记录见[最终证据](validation-evidence/login-refresh-fix-2.1.3/README.md)。
