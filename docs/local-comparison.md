# 本机新旧 UI 功能对照

两套 UI 已部署为独立 Docker 入口，连接同一个隔离的 Transmission **4.1.4** 服务。

| 界面 | 地址 | 来源 |
| --- | --- | --- |
| 旧版 Transmission Web Control | http://127.0.0.1:19080/transmission/web/?lang=zh-CN | old/src，只读；Web Control 1.6.1 |
| Vue 3 重构版 | http://127.0.0.1:19081/transmission/web/?lang=zh-CN | 已校验的 2.0.0 预编译 Release 快照 |

只绑定本机 127.0.0.1，当前对照服务没有登录密码。两套 UI 的任务、文件和 daemon 设置共享：一边开始、暂停、重命名或删除，另一边刷新后也会看到。数据放在 twui-compare 项目的独立 Docker 卷，不连接 NAS 或原实验下载目录。

标签、目录字典、列布局、主题和语言等浏览器数据按端口各自保存，不会因为共享 daemon 自动同步。验证迁移时，从旧入口导出后在新入口显式导入。

## 现成样例

| 样例 | 初始状态 | 适合核对 |
| --- | --- | --- |
| 对照-A-完整文件 | 暂停、100% | 完成大小、属性、校验、重命名、定位/移动 |
| 对照-B-等待下载 | 暂停、0% | 开始/暂停、队列、分类变化、勾选范围 |
| 对照-C-部分数据 | 暂停、50% | 进度、剩余大小、文件校验 |
| 对照-D-多文件与中文 | 暂停、50%，含多级路径 | 文件筛选、原始索引、wanted、优先级、中文显示 |
| 对照-E-目录匹配 | 暂停、0% | 部分匹配、下一候选、恢复原目录 |
| 对照-F-零字节文件 | 暂停、100%，含零字节文件 | 0 字节与多文件详情、完成判定 |

另有“对照-G-手动添加”种子，初始不添加：

- 浏览器下载文件：http://127.0.0.1:19081/comparison/fixtures/add-me.torrent
- 在 UI 的 URL 添加框使用：`http://modern:8080/comparison/fixtures/add-me.torrent`。这是 daemon 在 Docker 网络内可访问的地址；浏览器下载用上一条。
- 再添加同一个文件/URL，可核对 duplicate 结算。
- 所有样例使用本机空 Peer Tracker，不依赖外部站点；开始后可观察下载状态，不会从公网下载数据。

目录匹配对照使用 E，候选目录逐行输入：

```text
/data/comparison/candidate-a
/data/comparison/candidate-b
```

第一个候选有 50% 数据，第二个完整。测试完一套 UI 后可重置样例，再测另一套，保证初始条件相同。

## 建议比对清单

每项记录“旧版观测 / 新版观测 / 结论”。结论可区分功能缺失、已纠正的旧行为、交互调整和待确认。旧缺陷依据见 project_outline.md 第 17–21 节；不以重现旧缺陷作为新框架验收标准。

| 功能点 | 旧版入口 | 重构版入口 | 建议核对 |
| --- | --- | --- | --- |
| 版本与连接 | 底部状态栏 | 顶部连接/版本 | 同为 4.1.4，RPC 19；刷新失败后可恢复 |
| 全部/暂停/下载/校验分类 | 左侧导航树 | 左侧导航 | B 开始后分类、数量、速度更新 |
| 搜索与排序 | 右上搜索、列头 | 搜索框、列头 | 中文、名称/大小/进度排序及当前列表 |
| 目录/Tracker/标签筛选 | 导航树/配置 | 导航与筛选框 | 相同任务集合；本地标签先分别创建 |
| 选择与勾选 | 点击看详情，勾选后操作 | 详情选择与批量勾选独立 | 单行、Shift、页内全选、分页清理范围 |
| 右键操作范围 | 任务右键菜单 | 任务右键菜单 | 未勾选行与已勾选集合的范围提示 |
| 开始/暂停/立即开始 | 顶部工具栏/右键 | 工具栏/更多 | B；等待另一边约一个刷新周期再核对 |
| 队列四方向 | 队列子菜单 | 更多 | 排序按队列位置，检查实际位置变化 |
| 添加文件/URL/拖放 | 添加/拖放 | 添加/拖放 | G 种子；一次性目录不改全局默认 |
| 无效种子/重复添加 | 添加结果 | 逐项结果 | 合法项继续、duplicate、错误提示与关闭恢复 |
| 删除与删除数据 | 删除对话框 | 删除确认 | 是否显示目标范围与删除数据选择 |
| 属性和磁力链接 | 底部属性 | 底部详情/概览 | hash、有效完成大小、时间、分片与磁力链接 |
| 文件/路径/过滤 | 文件属性 | 文件详情 | D 的嵌套名称；过滤后操作仍作用原文件索引 |
| wanted 与优先级 | 文件操作菜单 | 文件按钮 | D；到另一边刷新确认服务端实际结果 |
| 任务名/路径重命名 | 右键/属性操作 | 更多/详情重命名 | A/D；失败提示与目标保持 |
| 移动与定位 | 移动目录 | 更多→目录 | 区分 move=true 与只定位，核对文件实际位置 |
| 任务限速/分享限制 | 任务配置 | 更多→限制/任务配置 | 保存、读回、取消、失败保留草稿 |
| 全局限速/替代限速/队列 | 设置 | 设置→服务端 | 设置共享，测试后恢复原值 |
| 端口/空间/blocklist | 设置/诊断 | 设置→服务端/诊断 | 显式触发、有结束状态、失败可重试 |
| Tracker 编辑与批量替换 | Tracker/扩展 | Tracker/更多 | URL、tier、预览、冲突与逐项结果 |
| Peer 和 IP 信息 | Peer 属性 | Peer 详情 | 本地样例无真实 Peer；外部查询仅在主动测试时使用 |
| 标签/目录字典 | 设置/导航 | 设置→本地数据 | 名称/颜色/说明、hash 映射、保存与重载 |
| 导入/导出/备份/重置 | 系统设置 | 设置→本地数据 | 先导出；daemon 差异单独确认，本地重置不删标签 |
| 自动目录匹配 | 扩展功能 | 更多→查找已有数据 | E；partial 等待、后项继续、下一目录、恢复和日志 |
| 列布局与详情尺寸 | 自定义列/拖动 | 列设置/列头/底部拖动 | 顺序、宽度、可见性及刷新后保留 |
| 主题/语言/移动端 | 右上主题/移动版 | 设置/响应式布局 | 中英、深色/系统主题、手机常用操作 |

外部 IP、在线 Tracker 与版本服务需按各 UI 的配置主动测试；本机样例不提供第三方服务，不能把未配置地址导致的提示判为功能缺失。

旧版按钮按其原有交互工作：仅点行查看详情不会启用批量暂停/删除等按钮，需勾选。跨页面操作后先等待轮询（默认约 5 秒）或手动刷新，再检查另一边的按钮状态。

旧源码未包含安装时备份的 `index.original.html`，旧版右上“原版”按钮在此环境没有该附件；本环境的两个比较对象是 Web Control 旧实现与完整重构版。为保持比较独立，代理只覆盖旧版现有配置项：默认全部任务、默认中文，并将其自动 GitHub 更新检查指向本机空结果；old/ 文件内容未修改。其他功能逻辑仍是原快照。

## 启动、暂停与恢复样例

```sh
# 已有本轮生成的 Release 时：准备校验快照、启动/构建 Docker、保留或首次生成样例
npm run compare:up

# 恢复自有样例，随后刷新两个页面；保留其他非样例任务与浏览器偏好
npm run compare:reset

# 停止对照环境，保留配置和下载数据卷
npm run compare:down

# 只读核对两个入口的健康和共同任务
npm run compare:check
```

`compare:reset` 只按样例 manifest 的 hash 移除对应任务，再重建已知样例路径；不会删除其他任务或移动到其他目录的文件。它不是整个 daemon 配置回退，也不重置两个浏览器入口的本地数据。

新代码重新构建 dist 不会悄悄改变当前比较快照。需要切换到新候选时先 `npm run release`，再 `npm run compare:up`，刷新新版页面。旧版始终读取 old/src。当前快照摘要见 `.lab/comparison/deployment.json` 或任一端口的 `/comparison/info.json`。

容器配置：lab/compare.compose.yaml；独立 Compose 项目 twui-compare。普通实验环境 twui-lab 可单独停止，不影响这两个入口。两 UI 静态代理是本机验证工具，不进入 NAS Release。对照后端配置和数据保存在 Docker 卷，重启保留通过 UI 保存的 daemon 设置。

## 已执行的基础验证

自动入口 `npm run test:compare` 使用真实两个地址，核对同一批任务和 4.1.4 版本，从重构版开始 B，再在旧版勾选并暂停，观察双方状态；最终恢复 B 为暂停。结果与截图保存在 artifacts/comparison-*，三个浏览器基础流程通过；实际通过范围另记在 validation.md，不把这条基础流程视为上表所有功能已经人工比对完成。
