# Detail Collapse and Piece Fixture

## Context
用户确认采用任务列表空白处收起详情，保护工具栏/搜索/菜单/弹窗，并新增较大分块样例供人工查看。原有详情有较小的×关闭按钮，选择通过app.select(null)关闭，但列表空白未接入；分块Canvas已按最多512格聚合，现有A仅4块。

## Decisions
- 事件仅绑定任务列表区域，只有左键点击非任务行/表头/交互控件/滚动条的空白处才调用select(null)。不监听document全局点击、window blur或visibilitychange；移动任务卡片同样受保护。点击工具栏/搜索/详情或teleport菜单、弹窗不会触发此规则。
- 保留批量checkedIds；清除详情选择与缓存、取消详情请求、递增序号，复用已有晚到响应隔离。修正关闭后detailLoading残留；再次点击任务正常加载。右上角×改为有名称和图标的收起详情按钮。
- 新增单独的对照-H-大分块预览，64MiB、4096块、每块16KiB；私有本机Tracker、暂停，真实数据校验到50%。512个可视格分为128格完整、256格各半、128格缺失，便于同时看到完整/中间/缺失色阶。大于512块时补简短汇总说明，不改变绘制算法或增加DOM规模。
- 仅新增自有目录/data/comparison/piece-preview-h、种子和任务，使用create-exclusive及稳定内容hash；存在相同hash则只读检查，绝不覆盖目录、不重新校验既有任务、不重置A–G或用户任务。只对首次新增H校验，等待真实暂停/分块位图并核对全部分块。保留独立manifest，不改原seed.json。
- 目标文件64MiB逻辑大小，约32MiB实际写入，缺失区为稀疏零且与预期非零内容不同。不启停、重建容器；夹具内Python仅沿用本机实验环境，不进入Release。

## Validation and Delivery
store单测验证取消加载/晚到响应/勾选保留；三浏览器验证任务/表头/搜索/详情/更多/弹窗不误关闭、空白和显式按钮关闭、重开、512格色阶。新H真实RPC核对4096位/50%/512格分布及既有任务关键字段前后一致；保留7任务供用户验收。运行相关静态/unit/build/spec/legacy，不重跑无关长测或四版业务矩阵（RPC字段/协议不变）。

新UI先准备候选；获本次快照授权后备份当前完整表格/导航/Logo静态资源与部署记录，再只更新19081，资源先行入口最后，保留旧哈希分块；回退仅还原该备份，不清任务或数据库。H可独立保留，不因UI回退删除。未提交、推送或发布；既有性能限制与DSM待验不变。
