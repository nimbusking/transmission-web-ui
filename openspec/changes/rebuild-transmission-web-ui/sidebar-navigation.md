# Sidebar Navigation Design

## Status
2026-11-15：详细实施计划已落入现有 spec-driven 主变更。本轮实现、相关验证和获授权19081快照更新已完成；完整性能数据达标但原运行器trace收尾失败，独立输出短测通过，实际证据与用户待验边界见docs/validation.md。保留当前未提交的Logo工作。用户已确认不要私有任务/私有种子节点。

## Context
- 实页19081仍为平铺状态按钮和目录/Tracker下拉框，没有层级、分组数量/大小或统计面板。
- `src/components/Workspace.vue` 的 categories 包含 private、没有 warning；folderOptions/trackerOptions 只构造下拉选项。
- `src/domain/torrents.ts` 的目录条件仅精确匹配；trackerHost 返回 hostname，丢失端口，不足以表达用户截图中的 modern:8080。
- `src/stores/app.ts` 已在串行 refresh 中读取 session-stats，但 stats 使用 Record<string, number>，未表达嵌套累计/当前会话对象；展示层未消费这些明细。
- 旧版参考：`old/src/tr-web-control/script/system.js` 的 resetNavServers/resetNavStatistics/resetNavFolders/loadFolderList，以及 transmission.torrents.js 的路径/Tracker聚合。实际旧入口加载压缩资源，后续行为核对须结合运行界面，不能只据可读源码断言一致。
- `project_outline.md` 第5.2节记录了旧版裁剪域名前缀、按Tracker数量猜测BT/PT等限制；`docs/traceability.md` 不代表新导航已验收。

## Goals / Non-Goals
**Goals:** 任务状态树、按Tracker分组、真实保存路径树、累计/当前会话统计、各级统一图标、键盘/移动使用、轮询期间保持展开状态、5000任务预算。

**Non-Goals:** 磁盘目录扫描、多daemon聚合、修改private标志、隐藏任务权限、Tracker连通性主动探测、任务控制重构、整体主题改版、Logo动画调整、旧界面像素复刻、DSM实机认证或对外发布。

## Decisions

### Navigation structure
顺序为全部任务、服务器分布、数据目录、数据统计、本地标签。全部任务是可筛选且可展开的一级节点，下设正在下载、已暂停、正在做种、正在校验、活动中、错误、警告。没有private节点。数据统计下分累计和当前会话，再各含五个只读指标。目录层级不限于二级；标签保留稳定ID/hash关联，不新增标签嵌套模型。

各级使用Lucide官方Vue图标组件，实施时核对兼容版本并锁定依赖；静态命名导入而非运行时加载整个图标字典。图标随构建离线提供并保留许可证，不使用图片、远端字体或CDN。服务器、文件夹、状态、统计、指标使用对应语义图标，装饰图标不重复朗读文字。

桌面保持左导航/列表/底部详情；侧栏宽度以长名称和数字可读为准小幅调整。折叠箭头、图标、名称和计数对齐，长文本省略并可查看完整值，深层视觉缩进设上限且完整路径始终可访问。移动复用同一导航组件与数据，展开不关闭菜单，选择筛选后关闭菜单。浅色/深色、键盘焦点均清晰。

### Node identity and interaction
节点使用类型前缀及无损稳定键：status:key、tracker:authority、folder:完整规范化路径、label:稳定ID、stats:scope:field。不得用显示文案、数组位置或有碰撞的字符替换作为ID。

展开按钮只改变展开状态，节点名称独立执行选择；服务器分布、数据目录、数据统计、本地标签的根节点只负责展开。统计行仅展示。全部任务名称清除状态/Tracker/目录/标签条件，保留可见搜索文本。

保留现有组合筛选：各维度相交，每维至多一个条件。列表显示所有生效条件及逐项清除入口，标题表达当前范围，结果为空时仍显示条件。筛选改变重置第一页并清批量勾选，不把范围缩小/扩大与展开操作混在一起。收起选中分支不取消过滤，祖先显示选中范围提示。

任务移动、删除或Tracker更改导致所选节点消失时，保留该筛选的稳定键及失效提示，显示空结果/清除入口，不自动切回全部任务。选择其他同维节点或清除条件后解除失效状态。

采用语义树或等价可访问结构，提供展开状态、层级、选中状态与可理解名称；方向键展开/折叠和移动焦点，Enter/Space选择，Tab可离开导航。虚拟化时聚焦节点必须在可见渲染范围内。

### Tracker grouping
优先从完整的任务Tracker基础字段派生分组，按URL解析后的小写hostname与有效端口生成authority；IPv6保留方括号。HTTP/HTTPS显式默认端口和隐式默认端口在各自协议下规范为同一有效端口；不同有效端口不合并，UDP按实际端口。不同协议但相同host/有效port归同一服务器组，协议和announce路径不是本轮站点身份。

显示主机及必要端口，不显示URL凭据、查询参数或passkey。不裁剪www/tracker/announce前缀。解析失败的URL进入无有效服务器信息的受控分组，不直接把原始敏感URL作为名称；缺失字段显示待补齐，明确空数组进入无Tracker组。

一次遍历任务，每个任务先对自己的authority集合去重，再累加count和totalSize。同任务可属于多个服务器组，跨组相加不等于全部任务总数。根节点按任务去重计算，不对孩子数值直接求和。成员身份与过滤使用同一分组函数，避免导航和列表口径不同。不得为了此功能顺带改变其他页面的Tracker排序/编辑语义。

### Path tree
输入仅为downloadDir，不查询磁盘、不使用本地目录字典作为实际目录。按路径段创建前缀树，完整规范化路径为ID，保留根身份与大小写；POSIX、盘符与UNC根不能互相合并。Windows形式才转换分隔符，POSIX文件名中的反斜线不能无条件改写；不解析符号链接或猜测物理目录。

父目录筛选本目录及所有子目录，使用路径段边界，/data/a不匹配/data/abc。叶/父节点均累计唯一任务数和totalSize；大小标识为任务总大小，不声称磁盘占用或已完成大小。缺失路径保留未就绪组，不误归根目录。数值字段未就绪时不把未知大小伪装成确定的0。

### Status and statistics
侧栏按已暂停、错误、警告、校验、下载、做种的优先级选取首个匹配的分类，列表与计数共用规则。已暂停按daemon的停止状态判断，任务行保留故障图标及原因。错误按任务error为2/3。警告包括daemon明确的Tracker warning，以及存在实际通告记录且lastAnnounceSucceeded为false的Tracker。成功的新响应清除对应警告。下载、做种和校验包含对应的排队状态。活跃任务可与主分类重叠，只统计正在下载或做种且有正上传或下载速率的任务。全部任务也包含状态未知且无故障的任务。

统计分别读取cumulative-stats/current-stats的uploadedBytes、downloadedBytes、filesAdded、sessionCount、secondsActive。filesAdded称已添加任务，当前会话明确指daemon会话。字节沿用应用单位，时长展示天/时/分/秒；0与未知区分，非法/负值显示不可用，不从现存任务求累计量。

增加明确的统计类型与接收边界，沿用refresh单链及generation保护，不新建计时器或独立轮询。统计未加载显示—；同连接失败保留上次值并标记过期；新generation先清空旧统计，晚到响应不能写入新连接。维持现有刷新错误结算，不扩大到同步框架重构。

### State and performance
组件只持有焦点/展开/筛选交互状态，派生树不回写Torrent。纯函数集中实现分组、路径前缀、分类和聚合；预计算映射，避免每个渲染节点扫描全部任务。复杂度以任务Tracker总数及路径段总数为界；名称/数值等变化使用稳定节点键，不重建用户展开状态。

展开偏好在现有SettingsRepository事务内按字段保存，RPC endpoint隔离；旧v2数据缺省时兼容默认值，不因新增可选设置重置标签、字典或列布局。未保存偏好时仅全部任务默认展开，服务器分布、数据目录、数据统计、本地标签及其后代默认折叠；用户主动展开后仍保存其偏好。只保留用户展开状态，不自动恢复过期的批量选择。多标签页更新不同设置不得覆盖；已经消失的动态键应有界清理，断线不能当作所有目录已删除。

大量目录/Tracker时只渲染展开后的可见节点并采用虚拟化，统计叶节点与普通导航一起可访问；折叠分支不创建全部DOM。保留现有任务表虚拟滚动与性能预算。性能路径发生变化，必须记录本轮冻结构建的完整30分钟结果，不复用Logo之前的长测结论。

| 目录 | 四级以上、父目录直接任务及子任务、a/abc、同名异父、根、中文空格、尾分隔符、POSIX反斜线/Windows根 | 领域单测与树交互 |
| 状态/统计 | 未通告不警告、失败→恢复、错误重叠、零值/未知、累计与当前、过期、重连晚到响应 | 单测/store测试 |
| 交互 | 展开不筛选、跨维交集、清条件/全部任务、失效节点、分页勾选、轮询不丢展开、重载/跨标签页偏好 | 三浏览器e2e |
| 呈现 | 深浅、长名、移动、键盘、焦点、图标离线、缺失翻译英文回退 | 三浏览器截图/断言 |

## Migration and Rollback
产品仍为静态前端；Node/npm/图标工具仅用于开发构建，完整Release在Linux、Docker、群晖安装运行不新增依赖。old/只读，两个compare入口和daemon数据不变，默认不运行compare:up/down/reset/test:compare等可能有副作用的命令。

本轮切换19081须有覆盖导航变更的明确授权；Logo轮授权不自动泛化。获授权后备份当时已含单流光Logo的快照与deployment.json，并记录摘要，不复用Logo改造前备份作为本轮基线。新包先校验全部资源/清单，资源先行、入口最后原子替换，保留旧哈希分块供旧页面懒加载；不重启容器。失败恢复本轮备份及部署记录，不删除任务/数据卷或用户偏好。

回退旧构建时新增可选导航设置可被忽略，禁止通过清空IndexedDB回退。构建dist不会更新19081；文档必须写明当前构建、归档和可见快照的对应关系。提交、推送、发布均按用户另行明确要求执行。
