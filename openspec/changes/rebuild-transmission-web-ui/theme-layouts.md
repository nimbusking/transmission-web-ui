# 布局主题与独立明暗模式

## Context
原设置页theme只控制light/dark/system，App统一Provider明暗，Workspace固定66/48页头工具栏与左侧导航。用户要求右上角独立提供3–4套改变布局的主题，左下太阳月亮切换深浅并持久化，形成可扩展Markdown规范。

## Decisions
提供workbench/console/studio/focus四种结构，默认兼容workbench；右上独立ThemePicker示意卡即时应用，左下ColorModeToggle按有效明暗切换，保留选择器底部恢复跟随系统入口。布局通过CSS根类控制唯一工作区，不重建任务/详情，不改勾选或列设置。小屏共同移动布局并保存主题，桌面恢复；工作室窄平板回公共页头，专注采用轨道和抽屉。完整规范见docs/theme-design.md。
ui.layoutTheme为可选兼容字段，缺失/未知回workbench，ui.theme明暗含义不变；沿用IndexedDB事务/通知/导入导出。两控件独立忙碌/错误反馈，主题不请求RPC或外部资源。

## Validation
旧v2/未知ID安全默认、并发明暗/布局事务及导入；三浏览器四主题实际几何区别、两种明暗、刷新保留/系统变化、选择详情列配置保持、窄屏与强制桌面/导航/浮层/键盘。只跑相关UI/存储回归与预算，不重跑四版RPC或压力长测，无协议/虚拟行渲染改动；性能13.12和DSM实机待验保持。

## Delivery
按本次连续验收直接更新19081无额外备份授权，冻结构建完成回归后完整预编译包、资源先行入口最后切换，保留旧哈希。不改任务/daemon、对照容器、old/，不提交推送或对外发布。回退可选workbench恢复默认布局或核验既有较早快照后恢复，后者会撤销此前多轮功能，不称精确上一版。

## 左下入口横排修正
按用户截图将品牌/版本文字组和明暗按钮放在同一footer横排，垂直居中，取消按钮独立fixed定位；在侧栏底部预留一行空间。专注轨道与移动导航关闭时只显示图标，移动展开后文字/按钮也同排，不出现第二个入口。以四主题/深浅/断点的实际几何检查为准，不改保存逻辑。
