# 文件列表分页与底部控制区

## Evidence and scope
旧版torrent-attribute.html的文件pager含条数/翻页/刷新/下载/跳过/优先级；system.js的pagerFilter对完整files数组做本地筛选和切片，内置全部、____padding_file及.url/.lnk/RARBG_DO_NOT_MIRROR.exe模板。旧文件列含已下载和名称/大小/进度/已下载/下载状态排序。新版已有虚拟滚动/原始index命令/正则及三种优先级按钮，缺分页、已下载列、排序、模板和文件专用刷新。

## Design
文件表下方增加自适应控制区：范围/匹配数/总文件数/已选数；独立页码、每页条数、跳页；文件刷新（只读当前files详情）、下载/跳过勾选文件、优先级下拉；路径输入、正则开关及三个兼容模板。模板仅筛选，不自动跳过/删除，清除恢复全部；保留无效正则提示。所有控件跟随现有四布局/皮肤/明暗和移动宽度，底栏不被虚拟表格挤走，窄屏可滚动详情而不使整页溢出。

先基于原始index合并files/fileStats/wanted/priorities，再全量筛选、全量稳定排序、按页切片，页内继续虚拟滚动。新增已下载列；名称/大小/进度/已下载/下载状态可排序。单文件和0文件仍显示范围（0–0）/分页，不能出现负页或越界。

filePageSize为独立可选v2 UI偏好，缺省200，允许10/20/30/40/50/100/150/200/250/300/5000及已保存合法值，10–5000范围；不复用/更改主任务列表pageSize，事务保存/跨页同步。页码/筛选/排序/勾选是当前详情临时状态；切任务重置，换页、条数、筛选或排序清空勾选。刷新缩小列表则钳制页码并仅保留当前页合法index。下载/优先级只操作当前页显式勾选的原始index，刷新期间不可重复提交；现有目标hash/generation身份机制不变。

## Verification and delivery
10,000模拟文件验证完整数据本地分页不新增翻页RPC、5000页内虚拟化、筛选/排序后的原始索引、选择清理/所有模板/非法正则/0项/单文件/页码收缩/偏好独立与重载、失败提示/重试、三浏览器窄屏及主题一致。必要unit覆盖筛选模板/排序和v2设置兼容。无新RPC方法、后端分页或无限请求；不声称减少完整文件元数据传输，也不复制旧版用页内位置误操作的缺陷。不创建/修改对照样例，不做无关长压力测试。完整离线Release后沿用直接更新19081、无额外备份授权，资源先行/入口最后，不操作容器生命周期；既有回退/真实DSM限制保持。
