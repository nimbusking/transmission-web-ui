# 全宽底部状态栏

## Scope
页头仅保留品牌/布局/主题。移除侧栏品牌版本文字，保留独立太阳月亮。新增横跨屏幕底行：左侧下载/上传/可用空间及Lucide矢量图标，右侧连接/Transmission版本/RPC/UI版本；各组内竖线分隔，左右留弹性间隔。桌面32px，含设备底部安全区；窄屏栏内横向滚动，不折行或推动整页溢出。列表分页仍属于内容区。

## Data
速度用每轮session-stats的downloadSpeed/uploadSpeed（B/s），不汇总筛选任务，不把缺失值补0。空间使用free-space(path=session-get.download-dir).size-bytes，含义为默认下载目录所在文件系统的可用空间，提示路径；不是浏览器磁盘、所有挂载总和或选中任务路径。四目标版本均支持此只读方法，不使用已淘汰download-dir-free-space字段。

空间查询复用单一串行refresh，不新增定时器，随自动刷新开关/手动刷新和后台降频；单次5秒超时。读取失败/缺字段/负数/非有限数显示不可用，不拖垮成功的列表和速度；断线保留最近成功值并明显标记过期。重连先清空空间/统计/session，generation和路径身份检查拒绝旧响应。下载目录由既有session-get最多30秒刷新识别变化；新路径请求失败不能保留旧路径的值。

## Layout and validation
以公共语义变量适配四视觉家族及明暗。四布局增设同一末行，移动详情/导航覆盖层底边停在状态栏上沿，不能遮住数据。UI版本构建时读取package.json，无运行时联网。验证非0与0、未知/失败/恢复/重连晚到、刷新开关、四布局/皮肤/明暗/窄屏、真实RPC速度和free-space与daemon文件系统只读比对。对照样例不启停、不写设置，不为非0速度证明操作现有任务。

## Delivery
完整预编译静态Release，沿用用户连续验收直接更新19081且不新增备份的授权；资源先写/入口最后原子替换，保留旧hash资源，不重启容器。既有较早快照可回退但会撤销多轮优化；真实DSM验收和既有长测性能问题不在本轮结案范围。
