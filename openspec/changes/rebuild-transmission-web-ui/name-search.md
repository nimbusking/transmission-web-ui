# 仅任务名称的多关键词模糊搜索

## Context
2026-11-16用户输入C后认为列表不变。当前7个样例路径均含comparison，原实现把名称/hash/目录拼接且忽略大小写，全部命中；真实19081已核对C为7项、对照-C为1项。本轮用户确认仅名称搜索，并明确采用部分名称/多关键词匹配；验收后沿用直接更新19081、无需备份授权。

## Goals / Non-Goals
只匹配任务名称，支持部分名称、忽略大小写、全角/半角兼容及空白分隔的AND关键词，顺序不限。保留当前排序、导航条件交集、120ms防抖、分页回第一页/清理勾选。仅主任务列表，不改文件详情过滤、RPC、任务身份、存储或既有第30节计划；不引入评分排序、错字纠正、正则、拼音、依赖或后台服务。

## Design
- domain/name-search.ts在一次selectTorrents调用中编译一次查询：NFKC标准化、toLowerCase、按Unicode空白分词、去重。非空查询对每个名称按相同规则标准化，所有词必须为名称中的字面子串，忽略词顺序。空词集合直接接受，不做名称标准化；缺失名称只匹配空查询。不修改原始任务名称。
- selectTorrents仅把t.name交给匹配器，hash/路径不参与文本匹配；这些字符串若本身出现在名称中可按普通文本命中。其他导航过滤和排序共用原实现，不改变hash操作身份或服务端字段。
- 中英文提示改为搜索名称及空格分词说明，历史语言沿用英文回退；现有Playwright定位同步更新，避免旧hash/目录文案残留。

## Acceptance and Validation
当前样例C仅命中C，comparison及仅hash中的文字零匹配；三体.S01.1080p.WEB-DL匹配三体和1080 三体，不匹配三体 2160；全角、大小写、空白、重复词、字面标点及空名称行为明确。三浏览器覆盖实时输入/中文组合提交、清空、计数/分页/勾选与详情保持、导航交集、移动及明暗和语言。5000受控任务短测记录筛选开销与端到端延迟，明确防抖/自动化包含情况，不替代既有13.12或30分钟结论。相关unit、静态检查、OpenSpec、old816、预编译资源预算均按本轮执行。
