# 任务操作

## Purpose
任务操作覆盖现有桌面有效业务，包括添加、控制、删除、队列、重命名、目录和限制设置；每个操作准确指向明确任务并区分请求确认和后台完成。

## ADDED Requirements

### Requirement: 添加结算
系统 SHALL 支持文件、URL、magnet、拖放及逐项结果，并在队列结束前完成标签保存。

#### Scenario: 添加结算的可观察结果
- **WHEN** 队列包含空行、重复任务、无效种子和有效种子
- **THEN** 忽略空行，逐项报告重复与失败，不中止其他项或丢失最后标签。

### Requirement: 写操作目标
系统 SHALL 对写操作捕获身份与非空目标，删除数据参数必须是boolean。

#### Scenario: 写操作目标的可观察结果
- **WHEN** 用户确认删除后改变选择或请求超时
- **THEN** 仅提交确认时目标，超时标记结果未知并核对，不自动重发。

### Requirement: 目录和默认值
系统 SHALL 区分移动数据、仅定位、本次添加参数和daemon默认设置。

#### Scenario: 目录和默认值的可观察结果
- **WHEN** 批量中第一项已在目标目录但其他项不同
- **THEN** 逐项计算和执行，默认目录仅在显式选择时修改。

### Requirement: 完整控制
系统 SHALL 提供启停、强制启动、校验、通告、队列、重命名和任务限制。

#### Scenario: 完整控制的可观察结果
- **WHEN** 用户执行适用于当前状态的命令
- **THEN** 构造正确method与参数，刷新目标并显示失败，草稿不污染已确认状态。
