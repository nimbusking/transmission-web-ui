# 任务同步

## Purpose
任务同步为任务浏览和操作提供唯一可信的服务端状态，明确首次快照、变更合并、缺失字段补齐、删除和重连边界，避免错误关联用户的操作目标。

## ADDED Requirements

### Requirement: 空实例启动
系统 SHALL 在零任务时完成首轮同步并持续调度。

#### Scenario: 空实例启动的可观察结果
- **WHEN** 首次连接空实例
- **THEN** 显示空态且以后新增任务可以出现。

### Requirement: 增量完整性
系统 SHALL 补齐新任务基础字段并处理删除，不按数量判断成员是否变化。

#### Scenario: 增量完整性的可观察结果
- **WHEN** 增量出现新ID或等数量成员替换
- **THEN** 新任务具有hash和目录，移除对象消失，新成员出现，警告恢复后清除。

### Requirement: 乱序隔离
系统 SHALL 拒绝过期连接或过期详情响应污染当前状态。

#### Scenario: 乱序隔离的可观察结果
- **WHEN** 请求任务1后选择任务2，任务1响应晚到
- **THEN** 响应只能更新有效任务1缓存，不改变任务2身份或详情。

### Requirement: 刷新调度
系统 SHALL 合并同类刷新并周期全量核对，隐藏页面降频。

#### Scenario: 刷新调度的可观察结果
- **WHEN** 服务响应慢于刷新间隔或recently-active遗漏变化
- **THEN** 无重叠同步链，最终由核对恢复一致，失败不清空有效缓存。
