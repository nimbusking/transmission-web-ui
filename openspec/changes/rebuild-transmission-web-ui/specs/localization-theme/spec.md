# 语言主题与格式化

## Purpose
语言和主题能力保证新界面在不同语言与明暗偏好下可读，明确缺失文案回退和历史主题迁移，同时让第三方查询保持用户可控且不影响核心管理功能。

## ADDED Requirements

### Requirement: 关于资料与项目身份
系统 SHALL 在关于弹窗复用当前静态Logo、package.json版本与已有会话版本，提供完整中英文字及历史语言英文回退，浮层跟随当前视觉皮肤和明暗。

#### Scenario: 关于正文可读性
- **WHEN** 在四种皮肤的深浅模式查看关于
- **THEN** 简介、字段标签和值、作者、版本标记、按钮及许可统一15px主体字号，标题保留24px层级；简介/字段/许可使用正常正文色，版本标记保留强调色，窄屏仍居中换行且无横溢出。

#### Scenario: 开发阶段的项目链接
- **WHEN** 查看关于或点击项目资料入口
- **THEN** 作者为nimbusk，主页及帮助/更新/许可链接指向当前仓库及对应文件，个人博客为https://nimbusk.cc；发布前使用更新记录文案，不将打开文档描述为自动版本检测，打开弹窗不访问第三方。

### Requirement: 语言回退
系统 SHALL 完整提供简中和英文，并迁移其他现有语言，缺失项回退英文。

#### Scenario: 语言回退的可观察结果
- **WHEN** 语言文件缺失、延迟或旧翻译无新增键
- **THEN** 启动不失败，相关文案使用英文且参数和数值格式正确。

### Requirement: 主题
系统 SHALL 支持light、dark、system并映射旧主题明暗偏好。

#### Scenario: 主题的可观察结果
- **WHEN** 修改主题或系统偏好改变
- **THEN** 所有主要组件协调更新并保存用户选择。

### Requirement: 外部查询
系统 SHALL 仅在用户主动触发时访问IP、Tracker列表或版本服务。

#### Scenario: 外部查询的可观察结果
- **WHEN** 首次加载应用或外部请求失败
- **THEN** 无后台第三方请求，失败可恢复且不影响RPC管理。

### Requirement: 统一品牌标识
系统 SHALL 在页头、空状态和浏览器 favicon 使用双向环流标识，全部资源随预编译包离线提供。

#### Scenario: 主题与小尺寸显示
- **WHEN** 用户在深色、浅色、移动布局或嵌套部署路径打开应用
- **THEN** 页头标识无裁切，空状态使用静态单色版本，入口通过相对路径提供 SVG favicon 和含 16/32/48 像素图层的 ICO 回退，不加载外部资源。

#### Scenario: 页头品牌副标题
- **WHEN** 用户在桌面或窄屏查看左上角品牌
- **THEN** WEB UI副标题使用10px字号，保留既有字距、颜色和主标题/Logo尺寸，四布局深浅模式下不裁切或挤出右侧入口。

#### Scenario: 箭头流动与减少动态效果
- **WHEN** 用户查看主页页头
- **THEN** 一段轻量流光沿上传和下载箭头交替循环移动，同一时刻最多出现一段流光，标识本体不旋转、不改变布局；空状态和 favicon 不播放动画；系统 prefers-reduced-motion 为 reduce 时取消流光与动画，保持完整静态标识。

### Requirement: 视觉主题与布局明暗分离
系统 SHALL 在右上提供独立布局和视觉主题入口，布局保留四套，视觉主题提供Modern/Metro/Material/Cupertino明暗配对；左下唯一明暗切换独立保存。

#### Scenario: 风格可辨与全域覆盖
- **WHEN** 在固定布局和明暗下切换视觉主题
- **THEN** 控件形态/填充/表面层级存在真实差异，导航/表头/菜单/弹窗等协调更新，布局坐标和虚拟行高不变，保留选择/详情/列设置且无daemon写入。

#### Scenario: 可访问与浮层
- **WHEN** 使用键盘、窄屏、减少动态效果或打开Teleport浮层
- **THEN** 两入口可达，焦点返回正确，菜单/缓存弹窗跟随同一皮肤，palette正文/辅助/主按钮对比度满足设计规范，矩形进度及状态颜色含义保持。

#### Scenario: 兼容与扩展
- **WHEN** 读取旧v2或未知视觉主题，或新增视觉家族
- **THEN** visualTheme安全回modern，布局和明暗/其他数据保留；注册schema共用白名单，新增实现遵循docs/theme-design.md。

### Requirement: 深色搜索框辨识
系统 SHALL 在深色顶部搜索框默认状态提供可辨的底色与实体边框，占位文字清楚，悬停/聚焦使用对应皮肤强调色。

#### Scenario: 四家族与输入
- **WHEN** 在四种深色皮肤默认/悬停/聚焦状态使用搜索
- **THEN** 默认边框相对底色/面板对比度>=3:1、占位文字>=4.5:1，不改变圆角/尺寸或筛选清空行为；浅色保持原风格。
