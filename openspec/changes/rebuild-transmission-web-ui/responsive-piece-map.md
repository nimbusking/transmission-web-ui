# Responsive Piece Map

## Context
用户提供三张新旧截图：当前图固定512px、8px步长且位于概览字段值列内，方格密集，整图title不能提供单格信息；旧版分块区独占底部整行、方格间距明显，悬停显示大小×完成率。旧system.js按最多500格汇总，但尾格按固定块数/大小计算会高估，不能照搬。

## Decisions
- 分块图移到概览字段列表之后，作为独占详情底部整行的区域；保留分块标题和汇总说明。填满可用内容宽度，不保留512px宽度上限。
- 单Canvas最多512格，目标边长18px、间距4px；根据容器宽度计算列数并均匀分配余量，不足一行保持同等大小。ResizeObserver跟踪容器、高清画布按设备像素比绘制，卸载释放观察和滚动监听。不增加逐块DOM或轮询。
- 悬停按画布实际坐标命中方格，间隙/末行空白不显示提示。复用Naive UI提示层，显示实际覆盖字节大小×完成率（百分比两位小数），附1起始原始分块范围。单格汇总仍明确标注；最后原始块按totalSize截断，汇总完成率按有效字节加权，不把缺失/未知大小伪造为完整块。
- 图内切换格、离开、滚动、调整宽度、数据变化和卸载均避免残留提示；保持详情内部点击不收起。键盘聚焦画布可查看首格并以方向键切换。
- 不修改daemon字段请求、任务、样例、存储、Logo或安装器；四版沿用现有pieces/pieceCount/pieceSize/totalSize。此轮为局部详情绘制，不重跑列表30分钟压力测试。

## Validation and Delivery
单测验证分块范围/尾块字节加权、异常元数据以及宽度/间距命中边界；三浏览器验证全宽、放大/间距、三色、hover完整/部分/缺失、间隙和尾格、resize/滚动隐藏、窄屏与详情保护。运行lint、类型/构建、unit、格式、OpenSpec、legacy和资源预算。先生成预编译候选与实际浏览器预览，获得本轮明确授权后才备份并更新19081；资源先行、入口最后，保留旧哈希资源。既有表格性能限制、DSM实机待验保持单列。
