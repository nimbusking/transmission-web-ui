# 更多批量操作与自动刷新核对（2026-11-16）

## 现状证据
更多复用了右键完整menu，与工具栏/队列重复。自动刷新已有单一setTimeout→refresh→finally schedule，按2–300秒/后台30秒读取列表和统计并持久化；关闭开关已清除定时器，但秒数输入未禁用、visibilityChanged未检查autoRefresh，dispose后的异步回调可能重新schedule。不会把“存在代码”直接当行为验证通过。

## 范围与方案
更多只保留全部暂停/全部启动/批量替换Tracker。前两项针对当前连接所有任务，通过refreshSnapshot等待在途/延后全量链结束，再完整只读刷新并冻结hash/generation与名称/数量，弹框确认（取消优先）；不受当前筛选/页/勾选影响，空列表/断连/忙碌不可发起，不用空ids表示全部。确认期间新任务不隐式加入，失效目标拒绝。全部启动用torrent-start（尊重daemon正常队列），全部暂停用torrent-stop；均复用逐项批量结果，提交后不在原窗口重复整批，部分失败需核对重新选择。Tracker替换只针对明确勾选，无勾选时该项禁用；全局操作使更多菜单无需勾选也可打开，这是用户对前轮更多禁用范围的明确调整，其他单任务/队列按钮继续仅勾选可用。

完整右键菜单独立保留，标签/强制开始/查找数据仍可从右键操作；已有匹配作业恢复入口保留。三个直接校验入口改为工具栏/右键，更多不再提供重复校验。后台作业不新增全局自动执行。

关闭自动刷新禁用工具栏秒数输入及加减按钮，设置页毫秒栏同步；保留原数值，重新启用恢复可改，不把关闭当数值清空。visibility回前台只在自动刷新开启时自动全量读取；启动/手动刷新/明确操作后的核对仍可执行，正在进行的读取允许结算一次。disposed防重挂定时器，并隔离销毁后晚到响应/延后全量。维持原刷新合并、最短2秒/后台30秒，不新增计时链或改变schema。
