## Design
桌面两栏，左栏传输限制：下载/上传开关与窄数值/KB/s同一行、最大Peer数、带宽优先级（低/普通/高）、遵守全局限速。右栏做种停止条件：分享率与空闲时间两行，每行清楚说明、模式下拉（跟随全局/自定义/不限制）及窄阈值，空闲加分钟单位。禁用/非自定义阈值保留显示但不可编辑；不展示裸枚举数字，不复制旧三态复选框难识别的交互。分组小标题/细分隔线，保存/重载置底；窄屏单栏、语义色/Naive主题继承，避让左下明暗按钮。

字段缺失/无效显示不可用并禁用对应编辑，绝不填0掩盖不支持。仅已知字段进入草稿基线；非法/空/非有限/越界/整数要求在写入前拒绝。速度0–2147483647整数；Peer/空闲0–65535整数；分享率0–1000000有限数（步长0.01），三态和优先级严格枚举。0是真实限制值，不代表不限。非启用阈值不提交，保留daemon已存值；重新启用会提交当前有效阈值。

## Save and lifecycle
加载捕获hash/generation与原值；只提交有效变化字段。写前读目标，若将修改的字段已被其他客户端更改，则拒绝覆盖并提示重载；不因无关字段变化阻止保存。写入后以同目标字段回读比对，仅一致才显示已确认保存。接受不等于应用；回读失败/不一致保持草稿并提示需重新载入核对，不自动重放写入。

脏草稿不被自动轮询覆盖；保存时禁用当前被提交任务的编辑，切换其他任务仍可编辑，旧保存的返回不能清除新任务草稿。重载按钮在有草稿时明确“放弃修改并重载”，读取失败不丢草稿。当前任务/连接身份变化隔离写入、回读与通知，匹配作业冲突沿用store防护。
