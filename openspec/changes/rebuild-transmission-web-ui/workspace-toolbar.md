## 工具栏勾选语义修正
用户截图确认：行高亮只代表查看详情，不得启用任务工具栏。原因是原Workspace的effectiveIds在checkedIds为空时回退selectedId。修正为工具栏仅使用checkedIds，所有任务快捷按钮和队列/更多入口均以勾选数启用；发送入口再次检查ready、busy与非空勾选，显式复制勾选ID后捕获身份。operate要求显式目标，取消selectedId隐式回退；右键传自己的明确范围，标签单元格继续单行目标，详情页内部配置不受影响。取消最后一项、取消全选、筛选或翻页清勾选后立即禁用，即使行仍高亮或详情仍开着；改名仍限单勾选。添加/刷新/设置/列设置/自动刷新不要求勾选。补桌面和移动回归、明确右键兼容与无误写；沿用本次工具栏验收修正的直接更新19081/不额外备份授权，不操作任务或容器。
