# 单入口发布安装器

## Why

用户要求将下载、检查、备份、群晖/Docker接入、验证及失败恢复纳入一个可直接执行的脚本。现有辅助脚本需要手工串联，已封板归档还因`./`路径和额外文档被安装器拒绝。UI业务保持封板，本变更只处理安装交付。

## What Changes

- 发布单文件`install-transmission-web-ui.sh`，嵌入同次发布的离线包；保留显式联网/归档高级参数。
- 自动识别已支持的SynoCommunity套件或本机独立Docker环境，预检真实服务、只读RPC和原Web资源。
- 持久化完整旧UI及接入备份，确认后安装/必要重启；验证失败、可捕获中断自动恢复，断电后的恢复使用同一入口。
- Docker保留旧容器及持久化卷，结构化保留配置；不可安全重建的编排/网络情形在修改前拒绝。
- 修正归档路径规范化、重复别名拒绝及存储版本回退校验。打包支持固定Web输入和独立安装交付版本，不重建或覆盖封板UI。

## Impact

影响release安装器、打包脚本、独立安装测试及用户文档。旧辅助脚本仍可单独使用且不自行重启；新整合入口根据用户本次授权在运行时提示并确认重启。不会操作19080/19081、真实NAS、下载任务、设置schema或主变更归档。
