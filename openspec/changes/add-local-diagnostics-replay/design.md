# Design

## Context
请求集中在src/services/rpc.ts，支持transport注入并已有错误分类；app store负责刷新代次、增量合并、批量执行和状态协调。现有测试具有RPC模拟基础。main.ts存在静态模块加载及顶层语言加载，Vue初始化后的监听不足以覆盖启动失败。构建已有source map，但缺少诊断所需的不可混淆构建标识。

## Goals / Non-Goals
目标：人工排障有上下文；约定用例可离线重放到同一故障状态；收集、脱敏、导出、导入、匹配、断言组成闭环。
非目标：保证复现所有浏览器缺陷、恢复被杀进程最后事件、还原服务端执行过程、记录用户全部数据或操作。纯视觉故障保留环境并允许用户另附截图，不宣称日志能自动还原像素。

## Decisions

### D1 两级采集与产品入口
默认模式记录摘要，允许关闭、清除和导出；不请求上传权限、不联网发送日志。增强模式用户显式启动，显示倒计时、容量和停止按钮，停止后导出。登录页与关于/设置使用同一诊断面板，显示当前模式、持久化是否可用、记录时间范围、丢失计数及重放资格。用户描述与截图为可选，文字说明也提示检查敏感信息。

增强录制以稳定检查点开始：等已有读请求结束，在无批量写入/目录匹配运行时，通过现有刷新链完成全量读取并冻结一份脱敏状态。10秒无法建立检查点则启动失败，已发生业务不取消、不重试写入。起点失败的记录仍可作为普通诊断导出。开启录制不改变自动刷新设置。

### D2 集中记录、显式业务埋点
新增src/services/diagnostics/下的schema、redact、recorder、storage、export模块；依赖方向为业务调用记录器，记录器不导入store。记录器入口不抛异常、不发RPC。rpc层记录逻辑请求及每次409尝试，store显式标记操作、刷新代次和丢弃过期响应；只在约定业务边界采集，避免全量watch状态或拦截全部console。跨await显式传operationId，不依赖全局“当前操作”。底层错误与上层展示共享errorId去重。

Vue errorHandler、window error、unhandledrejection与资源失败统一进入记录器；已捕获错误显式上报。正常409、取消、过期响应丢弃属于过程事件。异常栈记录脱敏脚本相对路径、行列，源码映射按buildId归档。

### D3 启动兜底
index.html放置独立、语法保守的少量启动脚本，先于模块加载监听错误，保存最多50条/64KiB内存事件；应用接管时合并并去重。启动失败显示不依赖Vue的文本提示和JSON下载入口。兜底不依赖IndexedDB、动态import或新浏览器API。脚本本身无法执行、浏览器崩溃和断电仅提供尽力记录，不能承诺捕获。

### D4 存储、隐私和资源限制
具体数据库、逻辑路径、期限、容量、格式及脱敏规则以log-contract.md为唯一依据。记录之前完成白名单转换，不先保存原文再导出脱敏。存储失败退回内存，UI提示；诊断库与用户设置库分离。持久化异步批量执行，最多1秒或50条刷一次，异常时尽力提前刷写，不依赖unload完成事务。

默认轮询成功摘要允许合并，增强事件不得采样或合并。达到增强上限时停止录制、标记不完整，绝不悄悄覆盖检查点。严重异常固定保留前后片段，后续正常轮询不能挤走已保存故障包。用户可以清除当前实例诊断数据，不能清除业务设置。

### D5 2.1.0可重放范围
支持：从检查点加载列表；全量/增量刷新；选择任务并读取概览；开始/暂停的批量执行；随后状态协调。支持网络异常、超时、409协商、401、协议异常、乱序与旧代次响应的录制回放。筛选/排序/主题/语言作为检查点配置保留；任意文本搜索输入不采集，不纳入自动操作回放。

其余操作仅记录名称、目标数量、结果和错误分类；增强录制遇到范围外且影响状态的操作即标记unsupported-action，停止可重放段。删除、文件上传、目录匹配、配置迁移及修改Tracker不纳入本期自动重放承诺。普通诊断包始终明确diagnostic-only。

### D6 重放引擎与一致性
新增开发入口scripts/replay-diagnostics.mjs，使用Playwright启动本地隔离应用，注入检查点到与业务共用的恢复适配器，通过同一store动作执行operation事件，不能只重播日志文本或展示录制终态。生产发行包不携带重放入口。

在导入包时校验schema、大小、事件序号、引用、摘要、检查点和覆盖范围。源版本精确匹配buildId；修复验证允许显式candidate模式并记录源/目标两个buildId，禁止默默用新版本冒充同版本重放。

使用可注入时钟驱动Date.now、performance时序、应用定时器及超时；传输匹配键为方法+规范化脱敏参数+操作上下文+该上下文请求序号，不能只按全局FIFO消费并发请求。记录每次请求发出、各attempt返回和最终完成的全局顺序；时钟按逻辑事件推进，重现响应交错。tag与409会话值使用合成映射，不能持有原认证信息。取消由记录的业务动作或调度触发，并断言匹配；禁止无条件伪造成功。

所有RPC及其他非静态资源请求在浏览器层阻断真实网络，transport仅消费包内输入；禁止访问源实例地址。模拟错误在真实RpcClient解析/错误分类边界发生，合法响应走真实解析路径；畸形JSON使用固定非法字节且保留原因类别。未匹配请求、剩余关键事件、时序冲突、缺字段立即失败，禁止回退真实请求或默认空成功。

在关键检查点比较独立录制的状态摘要：任务身份集合/状态、选中对象、stale、错误类别、批量成功失败数、代次及丢弃结果。输出matched、diverged或ineligible，并带首个差异。录制中的observed不是正确性证明；回归验证同时要求领域预期断言，避免把原缺陷当成应保持行为。

### D7 发布与验证门槛
buildId包含版本、commit和资源内容摘要，不只使用package版本；发布资产/source map与manifest按buildId保存，源码映射不得带开发机绝对路径。2.1.0需通过verification.md全部强制门槛；达不到则不能以“已支持重放”验收。文档和日志查看成功不能替代端到端重放证据。

## Risks / Trade-offs
脱敏可能改变字符串相关触发条件：记录transforms/losses，范围内必须保留类型、缺失/null/0、数组顺序、同一身份关联；必须删除的敏感字段参与分支时判定不可重放，不猜测原值。重放针对可控业务因果，不承诺同一底层浏览器错误跨引擎复现。增强数据体积较大，超限宁可明确停止，不无限增长。实际网络错误原因受浏览器限制，仅报告可观察事实，不凭TypeError断言CORS或DNS。

## Migration Plan
独立诊断库schema v1，不迁移既有设置。先实现协议与采集，再实现导出与重放，最后完成故障注入和发行包验收；各阶段不可把未验证能力标为完成。关闭采集立即停止新记录，保留数据供用户清除/导出；卸载/回滚不自动删除诊断库，旧版本不读取它。


## Implementation Decisions
2026-11-17：物理存储采用有界会话包聚合与独立容量索引，替代逐事件落库，详见log-contract.md第1节；性能优化前后实测均保留。补充operationCounter、轮询余量与原生任务因果边界，以消除三浏览器时钟调度差异；不改变业务超时和写入重试语义。Tracker白名单结构使用合成.invalid地址保留关联，不导出原地址或passkey。生产构建不含replay.html，开发重放构建与受控缺陷构建独立输出。
