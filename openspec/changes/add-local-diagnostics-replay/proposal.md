# Proposal

## Why
2.0 前端故障主要显示为临时提示，缺少环境、操作、请求和状态之间的关联证据。2.1.0 需要用户能够手动导出本地诊断包，并让开发者在隔离环境重放约定范围内的故障，验证原因和修复效果。

## What Changes
- 增加默认有界诊断、用户主动开启的增强录制、脱敏和手动导出。
- 增加启动异常、Vue异常、已处理业务错误、RPC过程及关键状态变化采集。
- 定义版本化JSON协议、浏览器存储生命周期、完整性与可重放资格判定。
- 交付开发侧离线重放工具和录制—导出—导入—重放端到端验证，不以日志查看器替代重放。
- 2.1.0必须同时交付有限范围的有效重放；不将其全部延期到后续版本。
- 不做自动上传、日志服务器、DOM录像、全站点击录制、真实daemon操作回放、通用时间旅行调试。文件上传、目录匹配工作流、任意设置导入不进入2.1.0自动重放范围，但保留诊断摘要。

## Capabilities

### New Capabilities
- `local-diagnostics`: 本地采集、隐私处理、有界存储、启动兜底与人工导出。
- `diagnostic-replay`: 有限业务范围的离线重放、资格检查和可核验结果。

### Modified Capabilities
无。现有主规格目录为空，本变更新增独立能力，不改写未归档2.0变更。

## Impact
涉及main、index.html、RpcClient、app store、设置/登录/关于入口、构建标识、独立诊断服务和开发测试工具；不改变RPC业务语义和现有设置数据库。新增文档见[设计](design.md)、[数据契约](log-contract.md)、[验证矩阵](verification.md)、[任务](tasks.md)。本变更已按授权实施并完成本地验收，版本号2.1.0；实际证据见implementation.md。本轮未部署或发布。
