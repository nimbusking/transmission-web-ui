# 验证计划与发行门槛

以下保留原验收门槛。实际执行结果见implementation.md及docs/validation-evidence/diagnostics-2.1.0/summary.json，已完成本地验收；OpenSpec校验本身只证明文档格式，不替代运行证据。

## 端到端方法
每条用例均通过真实应用动作触发，由真实记录器收集，点击导出后在全新浏览器上下文导入，卸除原服务并离线重放。禁止手写日志代替录制端验证。比对录制时独立读取的UI/store状态和重放实际状态，并断言不存在真实RPC。每项保存录制包摘要、buildId、浏览器版本、用例输入、期望/实际、消费统计和失败差异。

|编号|故障/场景|必须验证的结果|
|---|---|---|
|R01|首次409后成功；连续409耗尽|尝试次数、合成会话更新、最终协议错误一致；无误报重试写入|
|R02|暂停请求在服务端生效但响应丢失|超时和未知写结果重现；后续查询确认状态；暂停只执行一次|
|R03|401与网络失败|登录/过期状态、错误分类和轮询行为一致|
|R04|非法JSON、缺少torrents、tag不匹配|真实解析或业务校验路径产生同类错误，不泄露原响应|
|R05|全量与增量交错、旧代次响应晚到|最终身份集合正确、过期响应确实丢弃；请求匹配非FIFO|
|R06|快速切换选中对象触发取消|详情不串任务，取消不变成超时，顺序可重复|
|R07|批量启停部分失败|逐项结果、总计和后续协调一致|
|R08|受控注入前端状态合并缺陷|原构建重放确实触发缺陷；修复构建candidate模式同输入通过正确性断言，不能只断言原错误仍存在|
|R09|5000任务检查点/大响应触及上限|有界停止、明确ineligible；不截断后宣称可重放|
|R10|日志截断/缺事件/未知schema/错误buildId/范围外动作|明确拒绝与原因，无真实网络回退|
|R11|启动模块失败、语言加载失败、Vue异常、已捕获异常|从可用入口导出对应上下文；启动包允许diagnostic-only|
|R12|IndexedDB拒绝/配额不足/清除/刷新/多标签变化|业务继续，降级与丢失明确；不损坏设置；过期与跨实例隔离正确|
|R13|凭据、passkey、路径、magnet等金丝雀字符串|内存缓冲、IDB、导出、结果报告均不出现原值；关联与合法类型仍保留|

## 矩阵与量化门槛
- R01–R08在Chromium、Firefox、WebKit各连续成功3次，无非预期差异；使用受控逻辑时钟，不以增加等待掩盖竞态。
- Transmission 3.00、4.0.0、4.0.6、4.1.4分别从实验daemon录制基础列表/启停/协调用例，再断开daemon重放；使用合成任务，不操作用户真实下载。网络故障由实验代理或测试transport注入并标注，不能冒称daemon原生错误。
- 所有回放真实RPC请求数为0，关键事件消费率100%；缺失数据一律拒绝，不设置“尽量成功”阈值。
- 默认采集开/关各5轮5000任务同负载比较：刷新和交互p95回退均≤5%，额外保留堆内存≤10MiB，无诊断造成的>50ms长任务；增强额外堆内存≤30MiB。保存机器、浏览器、样本数及基线，若波动超过阈值先稳定环境，不删失败样本。
- R09–R13三浏览器通过；性能用Chromium固定环境。资源与清理上限验证覆盖事件、字节、TTL三种边界。
- 运行仓库check和相关E2E；使用最终2.1.0构建重新导出并重放，不只验证开发服务器。

## 交付证据
证据索引逐项列出通过/失败/未执行及原因，附可重放的合成完整fixture、自动测试命令和报告路径。至少保留一组R08修复前后证据。任何强制项未执行或失败，则2.1.0重放能力不可验收；不能用文档校验成功替代运行结果。
